# Android app

A thin Android shell (a Trusted Web Activity) that opens `https://briangossett.org/todo` full-screen in Chrome's engine. There is one codebase: every deploy of the site updates what the app shows, so the app itself rarely needs rebuilding.

- App name: **BG To-do** · package ID: `org.briangossett.app` · needs Android 7 or newer
- It is installed from an APK file, not from Google Play.
- The project in this folder was generated by Google's Bubblewrap library from the site's web manifest. `twa-manifest.json` records the settings.

## First-time setup

Needs JDK 17 and the Android SDK (`~/Android/Sdk`).

1. **Create the signing key** (once). It asks you to choose a password:

   ```bash
   ./create-key.sh
   ```

   Keep the password and a backup copy of `bg-todo.keystore` outside this repo. The key is gitignored and must never be committed. If it is lost, the app has to be uninstalled and reinstalled with a new key.

2. **Publish the key's fingerprint on the site.** `create-key.sh` prints a `SHA256:` line. Put that value in `public/.well-known/assetlinks.json` and deploy the site. This is what lets the app open without a browser address bar. The fingerprint is public information.

3. **Build the APK.** It asks for the key's password:

   ```bash
   ./build-apk.sh
   ```

4. **Install it.** Copy `bg-todo.apk` to the phone and open it (Android will ask to allow installing from that source), or with the phone plugged in and USB debugging on:

   ```bash
   ~/Android/Sdk/platform-tools/adb install -r bg-todo.apk
   ```

## Releasing a new version

Only needed when the app's name, icon, colors or start page change. Raise `appVersionCode` and `appVersionName` in `twa-manifest.json` and in `app/build.gradle`, then run `./build-apk.sh` and install the new APK over the old one.

## Regenerating the project

`tools/generate.js` is the script that created this folder from the live manifest. To run it again, install `@bubblewrap/core` in a scratch folder and run `node generate.js <path to this folder>` with Node 22 or newer. It overwrites the generated files.

## Google Play

Not set up. It would need an app bundle (`./gradlew bundleRelease`), a one-time developer registration with Google, and a review.
